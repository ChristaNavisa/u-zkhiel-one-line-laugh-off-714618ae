## The joke

> My toaster filed a restraining order — I proposed to the smoke alarm.

## How it works

`main.ts` (Node 22) writes exactly that one line to `/output/entry.txt` — a fixed
literal, deterministic, no network, no input. It refuses to run if the line ever
falls outside the bounty's gate (1–200 characters, not only whitespace). Run it with:

```sh
node main.ts
```
